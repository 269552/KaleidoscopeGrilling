| 资源 | 说明 | 数量 |

状态说明：

- 成品秘制烤串理论为 3×3×3 = 27 种几何状态。
- 串入过程中，第一个食物位不为空；后续食物位可为空，因此制作中状态需要支持空位。
- 食物模型共用，具体颜色随机/采样自食物贴图。

当前资源状态（2026-07-14）：玩家已提供木棍及每个槽位的模型 1；其余 6 个基础食物姿态已补齐，并由生成脚本产出 39 个有效流程状态。动态采色、熟制调色和模型覆盖代码已接入，后续仍可调整六种补充姿态的外形与各阶段色变参数。

## 五、分层渲染说明

固定串采用独立生串/熟串贴图，烤制中间态通过油光层与动态调色完成；秘制串采用模型位置 + 食物贴图色块采样。

```text
固定生串 / 秘制串模型
  + 油光层（半透明黄色光泽叠加） → 刷油视觉效果
  + 着色器调色（动态褐化）       → 翻面与熟成过渡
  + 黑烟/焦化反馈                → 超时预警与失败状态
```

| 层 | 内容 | 来源 |
| :--- | :--- | :--- |
| 固定串基础层 | 固定生串 / 成品串各 1 张 | 独立绘制 |
| 秘制串基础层 | 空签 + food1/2/3 动态模型 | 模型 + 采样 |
| 油光层 | 固定半透明光泽贴图 | 1 张通用 |
| 熟成调色 | 生、浅褐、金黄、焦糖、焦黑 | 代码/着色器 |
| 炒锅油层 | BER 叠加半透明油面，按油种改变颜色/贴图 | 3 张贴图或代码着色 |
