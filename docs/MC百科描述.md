[h1=🔥 森罗物语：烟火 Kaleidoscope Grilling]
为《森罗物语：厨房》扩展热食、风味油料、新食材与炭火烧烤，让每一道料理都带上温度与烟火气。
《森罗物语：烟火》是《森罗物语：厨房》的综合料理扩展，以烧烤、热食、油料与新食材为四条核心主线。
你可以种植油菜、洋葱、红薯与折耳根，在森林中寻找花椒树；也可以研磨食材、压榨菜籽油、调制不同风味的辣椒油，让炒锅、汤锅、熔炉和烧烤架做出的食物真正带上温度。
烧烤是最直观的入口，但从田间采集、食材加工到热气腾腾地端上桌，才是烟火所扩展的完整厨房生活。
[h1=📋 模组概览]
核心玩法：种植与采集 → 加工新食材 → 榨油与调味 → 烧烤或料理 → 趁热享用；
特色系统：热食与多种油料体系、新作物与联动料理、动态秘制烤串、16 种固定串、签谱、烤串餐盘、调料瓶、高级厨具架、趣味 Buff 与完整动作表现；
自由组合：玩家可以将不同食物穿上木签，动态生成带有食材颜色与玩家署名的秘制烤串；
厨房联动：新增食材、油料和料理可以与《森罗物语：厨房》的炒锅、汤锅、砧板、研磨、油壶和菜谱系统配合使用。
[h1=🎮 烧烤玩法]
[h2=手持穿串]
不需要打开合成界面：
1. 副手拿木棍，主手拿食材；
2. 右键将食材逐个穿到木签上；
3. 按固定顺序放入正确食材，可以完成固定配方生串；
4. 自由组合最多三种食材，可以制作带有玩家署名的秘制烤串。
潜行右键可以拆签，一次返还木棍和全部食材。
秘制烤串会从食材贴图中提取颜色，动态生成各不相同的串签模型。它的饱食度、饱和倍率和食物效果也会根据实际串入的食材计算，而不是使用固定属性。
[h2=固定配方烤串]
目前包含 16 种固定烤串：
牛肉串、五花肉串、鸡皮串、中翅串；
鱿鱼须串、鱼串、苕皮串、土豆片串；
猪儿虫串、蘑菇串、馒头片串、末影珍珠串；
丸子串、粘液串、骨肉相连串、煎蛋串。
每种烤串都有独立的食材顺序、食物属性、模型、Tooltip 和趣味效果。
[h2=烧烤架]
烧烤架一次可以放置 3 串食物。使用打火石点燃炭火后，完整流程为：
放入烤串 → 使用油壶刷油 → 翻面 4 次 → 使用特制调料撒料 → 取出成品。
烧烤过程中需要留意 HUD 与 Jade 给出的状态提示。拖延太久会得到“迷之烤串”或“黑暗烧烤”；刷油与翻面可以重新计算烤糊时间。
[h1=🧂 调料瓶]
调料瓶采用类似《森罗物语：酒馆》调酒系统的可见调制玩法。空调料瓶可以直接放置在地面，加入材料后，瓶内会逐层显示对应内容物。
[h2=调制流程]
1. 放置空调料瓶；
2. 加入花椒、洋葱粉、绿辣椒粉三种必要基础辅材；
3. 在总计 8 份的容量内继续加入材料，决定额外效果；
4. 取回“待摇晃的调料”，持续摇晃 4 秒；
5. 声音和粒子出现后，获得可使用 16 次的特制调料。
红石粉提供迅捷，火药提供力量，折耳根粉延长其他调料效果，不死图腾粉提供“重金属”，龙蛋粉提供“龙血”。瓶内累计至少 4 份花椒时，还会使食物获得“麻了”效果。
调料 Buff 只有在食物仍处于“热气腾腾”状态时才会触发。热食不会延长调料 Buff；折耳根粉才是控制调料 Buff 持续时间的材料。
[h1=🛢️ 榨油与油壶]
[h2=菜籽油生产]
1. 种植并收获油菜籽；
2. 将油菜籽研磨为菜籽粉；
3. 使用 8 份菜籽粉和 1 个小麦制作油饼；
4. 向榨油器放满 4 个油饼；
5. 使用铁砧反复砸击，前期也可以使用石头代替；
6. 在附近放置大缸，承接压榨出的菜籽油。
榨油共有 16 点进度：铁砧每次增加 4 点，石头每次增加 1 点。压榨完成后会产出油渣，油渣可以发挥相当于两次骨粉的催熟效果。
[h2=三种新增油料]
菜籽油：基础料理与烧烤用油；
辣椒油：提供更长时间的热食效果；
熔岩辣椒油：更强的高级油料，拥有发光流体与火焰粒子表现。
《森罗物语：厨房》的油壶最多储存 64 点油。1 点油可以刷 1 串，或者供炒锅完成一次加油。三种新增油料均可用于炒锅，并为盛出的食物提供不同时长的热食状态。
[h1=♨️ 热气腾腾]
刚完成的食物会带有“热气腾腾”状态，并随世界时间自然冷却。
✨ 热食会延长食物自身的正面效果，但不会延长调料 Buff；
✨ 辣椒油和熔岩辣椒油可以显著延长热状态；
✨ 热食饱和度倍率可在配置文件中调整，默认为 1.25 倍，且不会改变饱食度；
✨ 可选配置允许熔炉和烟熏炉产出的食物也获得热状态；
✨ 生食、熟食与热食在 Tooltip 和物品描边中具有清晰区别。
[h1=📜 签谱与烤串餐盘]
[h2=签谱]
将空白菜谱与生串放入合成栏，可以得到对应的签谱，记录过程不会消耗作为样本的烤串。
副手持木棍右键签谱，或者直接使用木棍右键挂在墙上的签谱，可以从背包中自动扣除食材并快速完成串签；食材不足时会给出提示。
固定串与玩家自制的秘制串都支持签谱记录。已记录的签谱也可以通过合成清除内容，重新变回空签谱。
[h2=烤串餐盘]
主手持任意烤串潜行右键完整方块上表面，可以摆下一只餐盘。每个餐盘最多叠放 5 串。
空手右键可以依次拿回烤串；破坏装有烤串的餐盘会得到“有烤串的盘子”；手持餐盘右键可以直接食用其中饱食度最高的一串，潜行右键则可以重新摆盘。
[h1=🔪 高级厨具架]
高级厨具架不只是装饰，而是一套面向厨房工作的快捷装备系统，使用方式类似《机械动力》的工具箱。
上方 5 个分类仓用于调料瓶、油壶等调味容器；
下方 4 个分类仓用于菜刀、锅铲、打火石等厨房工具；
长按 Caps Lock 可以打开两排式快捷界面，松开后切换到最终选中的物品；
支持记忆分类仓和一键回收背包中的匹配物品；
破坏高级厨具架后，内部物品与栏位记忆会保存在掉落物中。
其他模组可以通过公开物品标签和兼容 API，将自己的调味容器与厨房工具加入高级厨具架。
[h1=🌱 作物、采集与料理]
[h2=新增自然资源]
花椒树：较为稀有地生成于森林，可以采摘花椒并获取树苗；村庄战利品箱中也有中等概率找到花椒；
折耳根：可以从下界要塞战利品箱及下界疣种植区域获得，并可种植在耕地或灵魂沙上；
油菜：成熟后收获油菜籽，用于菜籽油生产；佩戴《森罗物语：厨房》的草帽打草也有机会获得；
洋葱：像胡萝卜一样直接种植洋葱本体，是基础调料的重要原料；佩戴草帽打草也有机会获得；
红薯：可以种植、烤制、研磨并进一步制作苕皮；佩戴草帽打草也有机会获得。
[h2=新增料理]
凉拌菜：凉拌折耳根、糖拌番茄、花椒蜂蜜；
炒菜：折耳根炒肉、青椒炒鱿鱼须、红烧鸡翅；
炖煮料理：土豆炖牛肉、红苕稀饭；
其他食物：烤红薯、烤鸡翅及多种食材加工品。
这些料理与《森罗物语：厨房》的炒锅、汤锅、砧板和研磨系统联动，并支持对应的模糊烹饪配方。
[h1=🎭 趣味效果与动作表现]
模组加入“麻了”“重金属”“重金属中毒”“龙血”等独立状态效果，并为部分效果制作了特殊的第一人称与第三人称表现。
穿串、拆串、刷油、翻面、撒料、摇晃调料瓶和砸击榨油器均拥有对应的声音或动作反馈，让料理流程不仅是界面与数值变化。
[h1=🖥️ HUD 与辅助信息]
烧烤架、榨油器、大缸、调料瓶和高级厨具架均提供对应的 HUD、Tooltip 或 Jade 信息，显示当前状态、容量、材料、进度和下一步操作。
使用 `/kg hud on` 与 `/kg hud off` 可以控制本模组屏幕 HUD，默认关闭。
动态烤串 GUI 缓存默认开启，使用 64×64 高精度图标降低创造栏和物品栏同时显示大量串签时的性能压力；玩家也可以在配置文件中关闭缓存，改用实时模型渲染。
[h1=🔧 模组适配与前置]
必须前置：森罗物语：厨房（Kaleidoscope Cookery）；
支持版本：Forge 1.20.1、NeoForge 1.21.1；
可选适配：Jade 用于显示方块状态、容量和操作提示；
开放兼容：提供烤串食材、固定串、油料容器、榨油容器和高级厨具架分类等标签或 API，方便其他模组扩展。
