# 森罗物语：烟火 - JEI 与 Jade 兼容待办

> 状态：后期兼容计划，当前不阻塞主体功能开发  
> 目标版本：Forge 1.20.1、NeoForge 1.21.1  
> 参考项目：`.breezeth/KaleidoscopeCookery-main`

## 1. 基本原则

- JEI 用于说明“怎样制作”，展示配方输入、加工条件、流程和输出。
- Jade 用于说明“方块现在正在做什么”，展示方块实体的实时内容和状态。
- 烧烤架、榨油器、串签和调料瓶配方均不得伪装成工作台合成配方。
- 需要为上述加工方式注册独立的游戏配方类型，并让 JEI 读取同一份配方数据。
- 凉菜当前使用普通无序合成，继续由 JEI 的工作台分类自动展示。
- JEI 与 Jade 均作为可选兼容，未安装时不得影响模组启动和主体玩法。

## 3. JEI 美术与布局交付

计划准备以下四张正式背景：

| 文件建议名 | 页面 | 建议画布 |
|---|---|---:|
| `grilling.png` | 烧烤架 | 176×102 或按内容加高 |
| `skewering.png` | 串签制作 | 176×102 |
| `oil_pressing.png` | 榨油器 | 176×102 |
| `seasoning.png` | 调料瓶 | 176×102 或按内容加高 |

背景图只负责面板、流程箭头及火焰、油、翻面、砸击等静态提示。具体食材、油品、调料和输出物品由代码动态渲染，不画入正式背景。

每个页面应同时提供两份文件：

1. 正式背景：透明 PNG，不含动态物品和标注文字。
2. 布局标注图：与正式背景尺寸完全一致，画出槽位色框、编号和用途。

布局标注约定：

| 标记颜色 | 含义 |
|---|---|
| 红色 | 食材输入 |
| 蓝色 | 油或液体输入 |
| 黄色 | 调料输入 |
| 绿色 | 主输出 |
| 紫色 | 副产物 |
| 白色 | 工具、容器或处理条件 |

- [ ] 打开像素网格后绘制标注图，禁止缩放正式背景后再标注。
- [ ] 普通物品槽按 18×18 像素规划，内部图标为 16×16 像素。
- [ ] 标明每个槽位左上角坐标，如 `食材1：(15, 24)`。
- [ ] 动态数量使用最大槽位布局；数量不足时由代码隐藏空槽。
- [ ] 重复食材仍分别占槽，如两个煎蛋显示两个煎蛋图标。
- [ ] 标明需要代码绘制的进度条、翻面次数、时间和说明文字区域。
- [ ] 编码前确认标注图与正式背景宽高完全一致。

## 5. 推荐实施顺序

1. 将烧烤、串签、榨油和调料流程的数据结构整理为稳定的自定义配方类型。
2. 先用纯色或森罗风格临时背景完成 JEI 功能验证。
3. 根据实际信息量导出四张 JEI 布局模板。
4. 制作并确认布局标注图，再替换正式背景。
5. 接入 Jade，优先完成榨油器和烧烤架实时状态。
6. 在 Forge 1.20.1 与 NeoForge 1.21.1 分别测试仅 JEI、仅 Jade、两者同时安装和均未安装四种环境。

## 6. 验收标准

- JEI 中的烧烤和加工内容显示在独立烹饪分类，而非工作台分类。
- 输入和输出均可通过 JEI 的“查看配方/查看用途”跳转。
- 动态槽位与标注图坐标一致，不发生图标重叠或越界。
- 重复食材、可替换标签食材和不同油品能够正确轮播或分别显示。
- Jade 展示内容与方块实体实际状态一致，多人客户端观察结果一致。
- 未安装 JEI/Jade 时不加载兼容类，不出现缺类崩溃。
- Forge 与 NeoForge 均完成游戏内验证。
