# 森罗物语：烟火 - 1.0 发布前完整审核清单

> 本清单是 1.0 正式版的发布门槛。所有项目必须有可复查的结果；“代码看起来正确”不算通过。

## 1. 注册内容与标签

- [ ] 导出 Forge 与 NeoForge 的全部物品、方块、流体、效果、菜单、方块实体注册 ID，逐项对照，确认两端名称和功能一致。
- [ ] 每个物品明确记录为“平台通用标签”“烟火私有标签”或“无需标签”，无需标签必须有理由。
- [ ] 作物、种子、蔬菜、生肉等同时核对 Forge `forge:` 与 NeoForge `c:` 的正确语义和目录形式。
- [ ] 烟火配方可替换输入统一使用 `#kaleidoscope_grilling:ingredients/*` 桥接标签。
- [ ] 成品输出、战利品、模型、粒子和代码注册引用保持精确 ID，不被误改为标签。
- [ ] 检查 `raw_skewers`、`grilled_skewers`、`kaleidoscope_cookery:meals` 的成员完整性。
- [ ] 不做语义过度兼容，例如鱿鱼须不得归入鱼类标签。

## 2. 数据与资源

- [ ] 解析 `common/src/main/resources` 下全部 JSON，确认无语法错误、未知类型和失效字段。
- [ ] Forge 使用 `recipes`、`tags/items`、`loot_tables`；NeoForge 使用 `recipe`、`tags/item`、`loot_table`，两套数据内容一致。
- [ ] 检查所有配方、战利品、世界生成、语言键、声音、模型、方块状态、贴图动画和渲染层。
- [ ] 检查所有注册内容在中英文下均无缺失翻译键，Jade/JEI 文本也包含在内。
- [ ] 对资源清单逐项核销；正式版不得保留非设计允许的原版占位资源、黑紫模型或缺失贴图。

## 3. 核心玩法回归

- [ ] 从生存新档完整走通：作物获取、种植、切制、串串、拆串、烤制、刷油、翻面、撒料、取串和食用。
- [ ] 逐一验证固定串、生串、秘制串、迷之烤串、黑暗烧烤的饱食度、饱和倍率、Buff、持续时间、音效和 Tooltip。
- [ ] 验证调料瓶 0～8 材料、缺料提示、摇晃、16 次耐久、堆叠放置、回收和 HUD/Jade。
- [ ] 验证三种油、油壶、大缸、榨油器 16 阶段、8 桶容量、满容器和无容器边界情况。
- [ ] 验证高级厨具架 5+4 分类仓、记忆空槽、Caps 快捷界面、最近方块选择、一键回收和服务端同步。
- [ ] 验证所有方块朝向、碰撞箱、选择箱、破坏工具、粒子、声音、透明与发光渲染。

## 4. 兼容与多人

- [ ] 分别测试仅必需依赖、完整森罗套件、农夫乐事及常见自动化模组组合。
- [ ] 验证 Farmer's Delight 洋葱与烟火洋葱能互换参与标签配方。
- [ ] 验证森罗炒锅、汤锅、菜刀、磨盘、热属性、料理分类和模糊配方联动。
- [ ] 验证公开 API、标签和数据包示例；无可选模组时不得出现类加载崩溃。
- [ ] 在独立服务端以两名玩家测试方块实体同步、动画、快捷 UI、调料效果和并发交互。
- [ ] 使用非管理员玩家测试所有网络包，服务端必须重新校验距离、物品和方块状态。

## 5. 构建与发布

- [ ] Forge 1.20.1 使用 Java 17 完成 `clean build`，NeoForge 1.21.1 完成 `clean build`。
- [ ] 两端各进行一次全新游戏目录冷启动，日志无配方、标签、模型、Mixin、网络或注册错误。
- [ ] 两端各执行一次 `/reload`，再次检查日志并复测数据驱动配方。
- [ ] 删除测试指令、临时聊天调试、开发占位和不应进入创造栏的内部物品。
- [ ] 核对版本号、模组名称、依赖范围、许可证、更新日志、README、兼容文档和资源清单。
- [ ] 对最终 JAR 解包核对内容，确认没有源码缓存、桌面素材、测试世界或隐私路径。
- [ ] 保存最终审核记录、构建日志和测试版本校验值后，才可标记 `1.0.0`。
