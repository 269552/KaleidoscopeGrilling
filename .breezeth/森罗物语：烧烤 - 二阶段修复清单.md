# 森罗物语：烧烤 - 二阶段修复清单

> 审计日期：2026-07-12  
> 审计基线：`kaleidoscope_grilling_design_v0.3.md`、Forge 1.20.1 当前源码、NeoForge 1.21.1 当前源码、两端现有客户端日志  
> 文档用途：进入二阶段代码修复时的唯一缺陷清单。完成一项必须同时修改 Forge 与 NeoForge，并按对应验收标准验证。

## 一、审计结论

当前工程可以在 Forge 1.20.1 与 NeoForge 1.21.1 完整构建，NeoForge 客户端也能进入标题界面，但这只证明注册和编译链路基本成立，不能证明主要玩法完成。

当前最严重的问题集中在以下部分：

1. 秘制烤串的数据、营养、熟制标记和继承效果流程均未按设计工作。
2. 签谱合成配方在两端运行日志中均明确解析失败，快速穿串还存在食材数量校验漏洞。
3. 烧烤架缺少破坏掉落规则、潜行全取、可视槽位、粒子音效和双形态。
4. 热属性只覆盖烧烤架产出的串，不支持设计要求的原版及其他模组食物。
5. 高级厨具架、四道森罗厨房联动料理、不死图腾粉来源、龙蛋粉来源完全缺失。
6. 三种油的流体方块模型在 Forge 与 NeoForge 运行日志中持续报错。

## 二、P0：阻断核心玩法

### P0-01 秘制烤串无法从任意模组食物开始穿串

- **设计要求：** 任意可食用 ItemStack 都能进入穿串流程，兼容所有模组；未匹配固定配方时生成秘制烤串。
- **代码现状：** `SkeweringHandler` 在第一种食材不匹配固定配方前缀时直接返回。只有先放入某个固定配方的第一种食材，后续偏离配方时才可能进入秘制串流程。
- **影响：** 大多数原版食物和第三方模组食物无法制作秘制烤串。
- **修复要求：** 固定配方匹配与“食物是否允许穿串”分离；任意可食用物品都允许成为第一个食材，固定配方只负责决定是否转换为固定生串。
- **验收：** 原版苹果、面包，以及一个带 NBT 的第三方食物均可作为第一种食材穿串。

### P0-02 秘制烤串读取不到自己的食材

- **代码现状：** 两端 `SkeweringHandler.read()` 都只允许读取 `unfinished_skewer`。物品转换成 `secret_skewer` 后，`readIngredients()` 永远返回空列表。
- **影响：** 秘制串 Tooltip 无食材，营养固定退化为 `1/0`，继承效果不触发，动态贴图也没有数据来源。
- **修复要求：** 数据读取支持半成品串和秘制串；固定串如需保留姿态数据，也应能读取姿态但不误读配方数据。
- **验收：** 三食材秘制串在物品栏、烤架、熟制后均能读取同一份食材数据。

### P0-03 未保存完整 ItemStack/NBT

- **设计要求：** 每个食材保存完整原始 `ItemStack/NBT`，以支持模组食物、动态贴图和实际食用继承。
- **代码现状：** 仅保存物品注册名字符串；拆串时重新创建无 NBT、数量为 1 的新物品。
- **影响：** 药水、附魔、自定义名称、数据组件、模组自定义食物参数全部丢失。
- **修复要求：** Forge 使用完整 ItemStack NBT 序列化；NeoForge 使用 HolderLookup/Data Component 兼容的 ItemStack 编解码。拆串必须返还原始副本。
- **验收：** 带自定义名称、药水内容和模组组件的食物穿串再拆串后数据完全一致。

### P0-04 秘制串熟制标记被旧数据覆盖

- **代码现状：** `GrillBlockEntity.extractOne()` 先执行 `setCooked(true)`，随后又把输入串的旧 Tag/CustomData 整体覆盖到输出，导致 `Cooked` 标记丢失。
- **影响：** 熟秘制串仍被判定为生串，无法可靠区分生熟状态。
- **修复要求：** 先复制输入数据，再写入熟制标记、热状态和调料数据；禁止后续覆盖。
- **验收：** 熟制后 `isCooked()` 为 true，重新进存档后仍保持 true。

### P0-05 生秘制串与熟秘制串营养公式未区分

- **设计要求：** 熟串使用统一公式；生串的饱食度与饱和倍率再乘 0.5。
- **代码现状：** 生熟共用同一个 `getFoodProperties()` 公式，没有 0.5 折减。
- **修复要求：** 根据熟制标记分别计算，并对 Forge/NeoForge 的“饱和倍率”字段语义做单元测试。
- **验收：** 使用设计文档中的示例食材计算，代码结果与手算完全一致。

### P0-06 食用继承没有模拟实际食用

- **设计要求：** 玩家实际依次食用每个原始食物，继承所有模组效果和副作用，但不继承原食物饱食度/饱和度。
- **代码现状：** 只遍历 FoodProperties 中预声明的药水效果，没有调用原物品食用流程，也未保留任意模组自定义行为。
- **修复要求：** 对每个保存的 ItemStack 调用真实食用完成流程；食用前后快照并恢复玩家饥饿值、饱和度和必要的消耗状态；热食将新增或延长的 Buff 时长翻倍。
- **验收：** 原版效果食物、森罗食物和一个通过自定义 `finishUsingItem` 赋效的第三方食物均能继承效果，但不额外增加饱食度。

### P0-07 签谱配方在两端均解析失败

- **日志证据：** Forge 与 NeoForge 的 `latest.log` 都出现 `Parsing error loading recipe kaleidoscope_grilling:skewer_recipe_book`。
- **根因：** 配方引用不存在的 `kaleidoscope_cookery:blank_recipe`；森罗厨房实际注册名为 `kaleidoscope_cookery:recipe_item`。NeoForge 还会受到 1.21 Ingredient JSON 格式影响。
- **附加问题：** `raw_skewers` 只有 1.20 的 `tags/items` 路径，没有 1.21 的 `tags/item` 路径。
- **修复要求：** 两个版本分别使用正确配方格式、正确物品 ID，并补齐 1.21 单数标签目录。
- **验收：** 启动日志无该解析错误，JEI/配方书能看到配方，实际合成能生成记录对应生串的签谱。

### P0-08 签谱快速穿串可在食材不足时产物复制

- **代码现状：** 每个配方位置独立扫描背包，但不会预留已选数量。三个相同食材位可能全部指向同一个数量为 1 的槽位，随后仍生成成品。
- **修复要求：** 使用按物品与槽位累计的消耗计划，先完整校验数量，再原子消耗；失败时不消耗任何物品。
- **验收：** 只有 1 个丸子时不能制作三丸子串；有 3 个时恰好消耗 3 个。

## 三、P1：主要系统缺失或明显偏离

### P1-01 穿串与拆串交互不符合设计

- **设计要求：** Shift+右键按后进先出顺序一次取出一种食材。
- **代码现状：** Shift+右键一次取消整串，返还全部食材与木棍。
- **修复要求：** 实现逐个 LIFO 拆串；最后一个食材拆下后返还木棍。若要保留“一键取消”，需另设独立操作并更新设计。

### P1-02 1～2 食材秘制串无法完成

- **代码现状：** 只有达到 3 个食材且未匹配固定配方时才生成秘制串；没有提前完成手势。
- **修复要求：** 明确并实现 1～3 食材秘制串的完成操作，同时不破坏逐个拆串。

### P1-03 秘制串制作者数据与 Tooltip 偏离

- **设计要求：** 保存 `CreatorName`、`CreatorUuid`，名称冻结；显示“玩家名自制烤串，谁也不知道究竟好不好吃。”，缺失数据时使用“某人”回退。
- **代码现状：** 只保存记分板名称 `Creator`，无 UUID；Tooltip 显示食材列表和“制作者：玩家名”，无指定文案和回退。
- **修复要求：** 按设计字段迁移，并兼容已有存档中的旧 `Creator` 字段。

### P1-04 动态贴图完全未实现

- **设计要求：** 动态贴图是必做核心能力；读取原食物贴图中段 4～8 个色块，映射到 food1～food3，按物品/NBT/熟制状态缓存。
- **代码现状：** 只有随机姿态数字和物品属性映射；全部串仍使用熟牛肉/生牛肉占位图，无贴图采样、材质槽映射、缓存或资源重载处理。
- **修复要求：** 实现设计 §12.3～12.4 的完整客户端渲染管线，并为无法读取贴图提供默认色组。

### P1-05 烧烤架没有方块实体可视渲染

- **设计要求：** 四个串槽在烤网上平铺显示，并表现油光、熟制阶段和焦黑阶段。
- **代码现状：** 没有 BlockEntityRenderer；槽内物品、翻面和阶段均不可见。
- **修复要求：** 两端注册烤架方块实体渲染器，读取同步后的槽位和阶段数据进行渲染。

### P1-06 烧烤架没有破坏掉落规则

- **设计要求：** 未刷油掉生串；已刷油未完成或完成未撒料掉迷之烤串；完成且撒料掉成品；焦化掉黑暗烧烤；不扣血。
- **代码现状：** `GrillBlock` 未覆盖移除/破坏逻辑，方块实体物品不会按设计转换并掉落。
- **修复要求：** 服务端统一生成阶段对应掉落，防止创造模式重复和活塞移动复制。

### P1-07 烧烤架取出操作不完整

- **设计要求：** 普通右键逐个取，潜行右键全部取。
- **代码现状：** 只有逐个取出，没有潜行全取。
- **修复要求：** 增加原子化全取流程，背包满时正确掉落到世界。

### P1-08 焦化结束没有掉落木炭

- **设计要求：** 20 秒焦化窗口结束后清空槽位并掉落少量木炭。
- **代码现状：** 直接 `clearContent()`，无任何掉落。
- **修复要求：** 按设计生成少量木炭，并保证每轮只触发一次。

### P1-09 烧烤架双形态、粒子、光照和动作反馈缺失

- **缺失内容：** 地面折叠腿/方块上平底形态、炭火粒子、微弱光照、刷油嘶嘶粒子、翻面反馈、撒料反馈、刷子动作表现。
- **代码现状：** 单一普通方块模型，无对应状态与客户端表现。
- **修复要求：** 先完成纯代码状态、粒子、声音和刷子动作挂点；正式模型贴图可继续使用占位资源。

### P1-10 热属性适用范围被缩小

- **设计要求：** 本模组、原版和其他模组食物都能附加热属性。
- **代码现状：** 只有从烧烤架正常取出的串会写入 `HotUntil`；没有通用食物附热接口或交互。
- **修复要求：** 提供通用热状态数据/API，并接入设计明确的使用入口；第三方 ItemStack 数据必须保留。

### P1-11 特制调料不能用于森罗炒锅

- **设计要求：** 特制调料也可在森罗炒锅炒菜时加入并触发调料 Buff。
- **代码现状：** 仅 `GrillBlock` 识别特制调料，未注入炒锅流程。
- **修复要求：** 参照森罗炒锅现有调料槽/翻炒流程接入，并避免与烧烤串消费次数重复。

### P1-12 高级厨具架完全缺失

- **缺失内容：** 方块、方块实体、配方、GUI、分类槽位、CAPS 可配置快捷键、快速换手逻辑。
- **修复要求：** 作为独立功能包实现；快捷键必须可配置且处理多人服务端权限与距离校验。

### P1-13 四道森罗厨房联动料理完全缺失

- **缺失料理：** 折耳根炒肉、青椒炒鱿鱼须、红烧鸡翅、土豆炖牛肉。
- **缺失内容：** 料理注册或兼容配方、营养、Tooltip、炒锅/炖锅配方数据。

### P1-14 不死图腾粉和龙蛋粉没有获取方式

- **设计要求：** 图腾经石磨 1:1 研磨；菜刀右键龙蛋获得粉，龙蛋瞬移但不损耗，并受抢夺影响。
- **代码现状：** 只注册物品和效果，没有石磨配方或龙蛋交互事件。
- **修复要求：** 补齐两端获取流程，并为龙蛋交互增加防重复触发和服务端校验。

### P1-15 折耳根未在地狱堡垒自然生成

- **设计要求：** 仅在地狱堡垒生成。
- **代码现状：** 作物可种植，但没有结构处理器、战利品入口或世界生成配置。
- **修复要求：** 选择不会破坏原结构的生成方案，并分别验证新旧区块。

## 四、P2：功能不完整、数据偏差与兼容风险

### P2-01 调料瓶反馈不完整

- **已实现：** 放置加料、容量 8、材料保存、4 秒摇晃、结束粒子声音、16 次耐久、基础 HUD。
- **仍缺失：** 每次加料动画/声音；Tooltip 的剩余容量、状态和 Buff 预览；HUD 的基础/高级材料分区与瓶身预览。
- **已确认修改：** 空瓶 HUD 也固定显示绿辣椒粉、花椒、洋葱粉，缺少时逐项标红；底部不再显示基础辅材总状态。这是用户后续确认的当前规则，不按旧设计回退。

### P2-02 调料瓶放置面约束未实现

- **设计要求：** 放在完整方块顶面。
- **代码现状：** 使用普通 BlockItem 放置，没有顶面/支撑检查，也没有失去支撑后的处理。

### P2-03 油壶 HUD 未按油种改造

- **设计要求：** 显示“油脂/菜籽油/秘制辣椒油/顶级辣椒油 + 对应单位”。
- **代码现状：** 只扩展油种和计数数据，没有修改森罗油壶 HUD 文本。

### P2-04 油壶方块状态同步存在风险

- **代码现状：** Mixin 保存油种，但设置油种/油量后未见显式 `setChanged()` 与方块更新包；客户端 HUD/渲染可能读到旧数据。
- **修复要求：** 对森罗油壶实际实现做联机验证，必要时在 Mixin 接口中补同步方法。

### P2-05 桶装油与刷油视觉缺失

- **缺失内容：** 三种桶装独立贴图、倒入颜色、油壶溢出颜色、三种油色刷子、油印和油光层。
- **现状：** 桶贴图使用水桶/岩浆桶/奶桶占位；流体本体使用水纹理加 tint。

### P2-06 三种流体方块模型持续报错

- **日志证据：** 两端日志对三种油的 `level=0..15` 全部报告 missing model。
- **修复要求：** 提供加载器正确的流体方块状态/模型配置；继续使用原版水纹理和 tint 也必须消除日志错误。

### P2-07 木榨油机缺少失败提示

- **设计要求：** 无可接收大缸、类型不符或容量不足时提示玩家。
- **代码现状：** 进度保留是正确的，但 `tryFinish()` 静默返回，没有反馈。
- **修复要求：** 撞击完成时向最近操作者或周围玩家发送节流提示，不能每 tick 刷屏。

### P2-08 压榨兼容 API 低于设计规格

- **设计要求：** 注册方块、最低下落高度、进度、撞击音效/粒子权重。
- **代码现状：** `PressImpactRegistry.register(block, progress)` 只有方块和进度；最低高度硬编码为 1 格，无声音/粒子参数。

### P2-09 大缸与榨油机破坏掉落未定义

- **代码现状：** 没有明确处理大缸内容、油饼、满进度和油渣在方块破坏时的保留或掉落。
- **修复要求：** 在设计中补充规则后实现，防止无提示吞物或复制。

### P2-10 签谱不能挂墙展示

- **设计要求：** 像森罗菜谱一样挂墙，显示对应串类。
- **代码现状：** 只有普通物品和右键快速制作，无方块/实体/渲染逻辑。

### P2-11 固定配方和效果不是数据驱动

- **设计要求：** 后续新增食材、串、调料和效果主要通过标签、配方与效果配置扩展。
- **代码现状：** 16 种固定串和全部调料效果硬编码在 Java 中。
- **影响：** 数据包不能扩展，第三方兼容需要修改核心代码。

### P2-12 固定串视觉只共用两个占位图

- **设计要求：** 16 种固定串最终应有独立生/熟资源，并支持油光/熟制阶段。
- **代码现状：** 所有生串共用生牛肉图，所有熟串共用熟牛肉图。当前可作为临时占位，但不能进入资源验收。

### P2-13 花椒树世界生成与战利品仍需实际验收

- **已修复代码：** Forge modifier 类型已改为 `forge:add_features`；NeoForge 使用 `neoforge:add_features`；树叶战利品已拆为独立池；1.20/1.21 标签目录已分别补齐。
- **未验证：** 新区块森林生成频率、树叶自然消失、空手/斧/剪刀/精准采集/时运掉落组合、树苗生长与结果再生。

### P2-14 去皮只产出原版去皮橡木

- **代码现状：** 花椒原木去皮后变为 `stripped_oak_log`，没有独立去皮花椒原木。
- **判定：** 设计未明确要求独立去皮木，可暂时接受；若正式资源需要完整木种，应补注册项和配方。

### P2-15 创造栏实现记录与旧代码并存风险

- **现状：** 独立创造栏会遍历本模组注册物品；`ModItems.addToCreativeTabs()` 仍保留向原版食物栏添加物品的旧方法，但当前未见监听注册。
- **修复要求：** 删除未使用旧入口，避免后续误接导致重复展示。

## 五、设计文档自身需要先确认的冲突

以下条目不能由程序员自行猜测，修复前应先在 v0.3 设计正文统一：

1. **固定串数量冲突：** 文档正文已有 16 种固定串，但“食物总表”仍写烤串 14 种、总计 20 种。按当前内容应为 16 固定烤串 + 2 熔炉食物 + 2 凉菜，共 20 种成品，但表格文字需要修正。
2. **原版油脂冲突：** §4.1 前文说原版油脂可赋予 60 秒热属性，后文又写原版油脂不能作为烧烤刷油材料。需明确它通过什么入口给食物附热。
3. **秘制辣椒油配方冲突：** 主表仍写“红辣椒沫×3 + N”，代码实现记录又称 N 未确认；实际代码已擅自实现为“菜籽油桶 + 红辣椒粉×3”。需确认最终原料后再修配方。
4. **茄子、黄瓜状态不清：** 作物章节仍按正式内容描述，但当前食物总表和代码均未纳入。需标记为明确暂缓或重新进入二阶段范围。
5. **秘制串最少食材数未明确：** 文档说最多 3 种，但没有明确 1 个或 2 个食材如何结束穿串。需确认完成手势。
6. **HUD 规则已被后续确认修改：** 当前应以“空瓶也显示三项必需材料、逐项标缺少、无底部总提示”为准，同步回 v0.3 正文。
