| 油壶（顶级辣椒油使用态） | 复用森罗油壶轮廓，但修改壶口溢出油色、滴落像素与油印颜色 | 1 |
| 刷油动作刷子 | 油壶使用动画/第一人称表现中出现刷子或刷头蘸油刷过烤串；按油种区分菜籽油刷子、秘制辣椒油刷子、顶级辣椒油刷子；不可获取，不放入创造物品栏，Tooltip 注明“不可获取物品 / 仅用于刷油动作表现” | 3 套动作/使用态资源 |

说明：

- 不再新增搪瓷油刷杯；刷油复用并修改森罗厨房油壶。
- 油壶本体轮廓复用森罗厨房资源，但必须按油种修改溢出油色、滴落/油印颜色，并在刷油动作中表现对应油种刷子。
- 三种油都需要统一颜色配置：流体颜色、桶装倒出/倒入颜色、油壶壶口溢出颜色、滴落/油印颜色、刷到食物上的油光层颜色。
- 三种油分别需要对应刷子/刷头油色表现：菜籽油刷子、秘制辣椒油刷子、顶级辣椒油刷子。
- 油桶右键方块状态油壶时播放对应油色的倒入表现；菜籽油额外支持倒入大缸，秘制辣椒油与顶级辣椒油只进油壶。
- 旧“配方单”改为“签谱”。

### 3.6 秘制烤串动态贴图/模型

秘制烤串不为每种组合绘制独立贴图，必须做动态贴图系统。

| 资源 | 说明 | 数量 |
| :--- | :--- | :--- |
| 空签模型 | 玩家手持木棍串入食物前/动态串底模 | 1 |
| 食物位模型 | food1、food2、food3 三个位置，每个位置支持空/模型1/模型2/模型3 组合 | 3 位置 × 3 食物模型 |
| 食物色块采样 | 从串入食物中段取 4-8 个色块，映射到食物位模型材质 | 代码动态生成 |
| 油光层 | 刷油后半透明光泽叠加 | 1 通用 |
| 熟成/焦化调色 | 生 → 浅褐 → 金黄 → 焦糖金黄 → 冒黑烟 → 焦黑 | 着色器/动态调色 |

状态说明：

- 成品秘制烤串理论为 3×3×3 = 27 种几何状态。
- 串入过程中，第一个食物位不为空；后续食物位可为空，因此制作中状态需要支持空位。
- 食物模型共用，具体颜色随机/采样自食物贴图。

## 五、分层渲染说明

固定串采用独立生串/熟串贴图，烤制中间态通过油光层与动态调色完成；秘制串采用模型位置 + 食物贴图色块采样。

```text
固定生串 / 秘制串模型
  + 油光层（半透明黄色光泽叠加） → 刷油视觉效果
  + 着色器调色（动态褐化）       → 翻面与熟成过渡
  + 黑烟/焦化反馈                → 超时预警与失败状态
```

| 层 | 内容 | 来源 |
| :--- | :--- | :--- |
| 固定串基础层 | 固定生串 / 成品串各 1 张 | 独立绘制 |
| 秘制串基础层 | 空签 + food1/2/3 动态模型 | 模型 + 采样 |
| 油光层 | 固定半透明光泽贴图 | 1 张通用 |
| 熟成调色 | 生、浅褐、金黄、焦糖、焦黑 | 代码/着色器 |
