# Kaleidoscope Grilling Fabric 26.2 Port

## Preview 1 milestone

A deliberately small playable build is now being compiled so there is a real jar to test while the full port continues.

Enabled in Preview 1:
- Fabric 26.2 / Java 25 entrypoint
- Original `kaleidoscope_grilling` namespace and IDs
- Creative tab
- Big Vat as a placeable block/item
- Beef Chunks
- Chicken Skin
- Squid Tentacle
- Minced Houttuynia
- Carrot Dice
- Potato Slice
- Raw Mantou Slice
- Green Chili Powder
- Sichuan Pepper
- Existing Grilling textures/models/lang assets

Temporarily disabled in Preview 1:
- Legacy 1.21.1 datapack recipes
- Grill machine logic
- Oil press / fluid transfer logic
- Skewer eating and threading systems
- Seasoning behavior
- Network sync
- Client HUD/render hooks
- Worldgen/loot events
- Optional Create / Maid / KubeJS compatibility

Those systems remain the next stages of the full port. Preview 1 is not being labeled as the finished port.
